The manuscript "Quantum Many-body Simulations from a Reinforcement-Learned Exponential Ansatz" by Yuchen Wang and David A. Mazziotti develops a reinforcement learning approach to solving the contracted Schrodinger equation (CSE) for the ground states of many-body molecular systems.  Code for the Reinforcement Learning Contracted Quantum Eigensolver (RL-CQE) is presented in the accompanying Jupyter notebook.
